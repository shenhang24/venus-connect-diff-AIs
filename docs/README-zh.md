# Venus 0.8.0 中文简介

Venus 是本地、可编辑、可追溯的个人知识工作区。你导入有权使用的资料，系统通过已配置、已支持的 Codex／AI 入口发起处理，保存真实结果、显示状态并从断点继续，无需聊天反复催跑。

四层各有用途：

- **Vault**：保留原对话／Markdown 和来源，不用摘要替代原文。
- **AI 知识点**：提炼供检索的事实、经验和关联，保留证据与不确定性。
- **AI 技能**：把相关知识、共同设定、criteria 和变体组织为完整 Prompt，再加本次任务增量。
- **概念云**：给人阅读项目总览、认知综述和完整专题页，区分用户信息、建议和推断。

共用“大标签→项目→内容／子主题”导航。项目可多归属，但引用同一身份，不复制资料。组织规则与模板可以继续调整，原文、人工选择和来源保持可追溯；这不是无限自主改写。

可以暂停、续跑、重置任务或明确范围重新运行。只有服务运行、处理已启用且分析入口可用时，后台工作才会继续。只读接口返回的上下文需要调用方实际使用，不能保证当前聊天已自动接入。
