Unedited browser JPEGs show the actual application. All text and example relationship explanations are synthetic; topology and scale are anonymized. The fixture has 15,063 records (372 Vault, 11,651 knowledge, 2,743 skills and 297 concepts). It is not published as a library. Original private text, identifiers, credentials and configuration are excluded.

Analysis is disabled and network animation is paused. No inference calls were made. Metadata/colors are precomputed examples; these are neither real-library completion receipts nor performance benchmarks. Close-ups show a local scope. Focus view is an actual reversible display control: it hides status panels/diagnostics without stopping tasks. Turn it off for processing details.
